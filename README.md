
X.ZON installable package (v131 + PWA)

Files (keep this folder structure):
  index.html            the app (v131, only the <head> changed: manifest, icons, service-worker registration)
  manifest.webmanifest  install info
  sw.js                 offline app shell
  icons/                app icons

Free hosting (GitHub Pages):
  1. Create a free GitHub account and a new PUBLIC repository (e.g. xzon).
  2. Upload everything in this folder (keeping icons/ as a folder).
  3. Settings > Pages > Source: "Deploy from a branch" > main > / (root) > Save.
  4. Open https://<your-username>.github.io/xzon/ on the iPad in Safari.
  5. Share button > Add to Home Screen.

BEFORE moving: in your current X.ZON, Settings > Your data > back up. Open the installed app and restore.
Audio files are not part of the backup; re-import them in the installed app.
